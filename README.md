# High-Impact Prompting with ChatGPT

Participant site for the WTPD workshop, Tuesday, November 10, 2026.

Live at https://willardwonder.github.io/prompt/

- `index.html`: the workshop path. Ten stops with copyable prompts, built-in exercises, and a "My task" plan that saves in the participant's browser and prints as a one-page plan.
- `handout.html`: two-page printable reference.

No build step and no dependencies beyond Google Fonts. Flat Cap Co. is a fictional practice company.
