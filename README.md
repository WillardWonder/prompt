# High-Impact Prompting with ChatGPT

Participant site for the WTPD workshop, Tuesday, November 10, 2026, 8:30 to 10:30 AM, Room A107.

Live at https://willardwonder.github.io/prompt/

- `index.html`: the full two-hour workshop on one page, in order, with clock times. Every prompt has an Open in ChatGPT link (new chat) or a Copy button (same chat / attach files). Participant work saves in their browser and prints as "My plan".
- `handout.html`: two-page printable reference.
- `files/`: Flat Cap Co. practice files (fictional company).
- `assets/`: shared styles and script. No build step.
